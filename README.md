# 🚖 Taxi Booking Application

A full-stack Taxi Booking Web Application built using Spring Boot and Thymeleaf.

## 🚀 Features
- User booking form (pickup & drop)
- Admin dashboard
- Contact form
- Secure login/logout (Spring Security)
- Responsive UI (HTML, CSS, JS)

## 🛠️ Tech Stack
- Java 25
- Spring Boot
- Spring Security
- Thymeleaf
- MySQL (configurable)
- HTML, CSS, JavaScript

## 📁 Project Structure
- Controller → Handles requests
- Service → Business logic
- DAO → Database operations
- Templates → UI (Thymeleaf)

## ▶️ Run Locally

```bash
mvn clean install
mvn spring-boot:run
